# Darkrai + Cresselia Events

Add two Generation IV legendary encounters to Kanto's postgame.

After becoming Champion, visit Pokémon Tower at night to begin the **Darkrai** event. Darkrai escapes into Kanto as a roaming Pokémon, turning the encounter into a hunt rather than a single stationary battle.

Once the Darkrai event has begun, **Cresselia** can appear at night in Mt. Moon's old fossil chamber. If Cresselia is defeated instead of caught, it can return later.

## Features

- Postgame Darkrai event at Pokémon Tower
- Darkrai becomes a roaming Pokémon after the encounter
- Follow-up Cresselia encounter in Mt. Moon
- Events are tied to the real-time day/night cycle
- Cresselia remains obtainable if it is accidentally defeated

Install the required mods, then install **Darkrai + Cresselia Events** through G1R Deluxe's mod browser or import the mod ZIP manually.
